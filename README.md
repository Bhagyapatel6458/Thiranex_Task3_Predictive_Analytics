# Predictive Analytics Using Historical Data

## Overview
A machine learning project to forecast future sales trends using historical data.
Built as part of an internship task to demonstrate predictive modeling,
trend analysis, and data-driven forecasting.

## Key Features
- Data preprocessing and cleaning
- Linear Regression model training
- Model evaluation (R², MAE, RMSE)
- Actual vs Predicted visualization
- 6-month future sales forecast

## Model Results
- R² Score : 0.9651
- MAE      : 71.64
- RMSE     : 85.56

## Technologies Used
- Python 3.12
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Structure
- `sales_forecast.ipynb` - Main Jupyter Notebook with all code

## How to Run
1. Clone this repository
2. Install dependencies:
   pip install pandas numpy matplotlib scikit-learn jupyter
3. Open `sales_forecast.ipynb` in Jupyter Notebook
4. Run all cells in order

## Expected Output
- Dataset with 47 records and 3 features
- Trained Linear Regression model
- Accuracy metrics printed in console
- Actual vs Predicted sales chart
- 6-month forecast chart
